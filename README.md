# To-do List — 날짜별 할 일 관리

HTML, CSS, JavaScript로 구현한 날짜별 할 일 관리 학습 프로젝트입니다. 날짜를 선택하고 할 일을 추가·수정·삭제하거나 완료 상태를 변경할 수 있습니다. 데이터는 브라우저의 `localStorage`에 저장됩니다.

- **제작자:** 홍정기
- **저장소:** `Jeong-Hong/CH2_javascripts_todo_list`
- **실행 방식:** 별도의 빌드 과정이나 백엔드 없이 실행하는 정적 웹 페이지

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 날짜 선택 | 선택한 날짜의 할 일만 표시하며 입력 폼을 펼침 |
| 할 일 추가 | 날짜, 제목, 내용과 초기 완료 상태를 저장 |
| 목록 조회 | 선택한 날짜에 해당하는 항목을 등록 순서대로 표시 |
| 할 일 수정 | 목록 안에서 제목·내용을 수정하고 저장하거나 취소 |
| 할 일 삭제 | 삭제 버튼으로 해당 항목 제거 |
| 완료 및 완료 취소 | 완료 상태를 전환하고 제목·내용에 취소선 표시 |
| 브라우저 저장 | 변경 내용을 `localStorage`에 저장하고 다음 접속 시 불러오기 |
| 기본 입력 검사 | 날짜 또는 제목이 비어 있으면 신규 등록을 막음 |

## 사용 기술

- **HTML5:** 날짜 입력, 폼, 목록 및 시맨틱 영역 구성
- **JavaScript:** DOM 조작, 이벤트 처리, 배열 기반 상태 관리, JSON 직렬화
- **CSS3:** 입력 폼 표시 전환과 완료 상태 취소선
- **Tailwind CSS CDN:** 레이아웃, 색상, 여백 및 버튼 스타일
- **Web Storage API:** `localStorage` 기반 데이터 저장

## 실행 방법

### VS Code Live Server

1. 저장소를 복제하고 VS Code에서 엽니다.

   ```bash
   git clone https://github.com/Jeong-Hong/CH2_javascripts_todo_list.git
   cd CH2_javascripts_todo_list
   code .
   ```

2. **Live Server** 확장을 설치합니다.
3. `index.html`을 우클릭하고 **Open with Live Server**를 선택합니다.

### Python 로컬 서버

Python이 설치된 환경에서는 저장소 최상위 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000`에 접속합니다. 환경에 따라 `python` 대신 `python3` 또는 `py`를 사용하세요.

> Tailwind CSS를 CDN으로 불러오므로 스타일을 정상적으로 적용하려면 인터넷 연결이 필요합니다. 저장 동작을 일정한 환경에서 확인할 수 있도록 HTML 파일 직접 실행보다 로컬 HTTP 서버 사용을 권장합니다.

## 사용 순서

1. **날짜 선택**에서 할 일을 등록할 날짜를 선택합니다.
2. 나타난 입력 폼에 제목과 내용을 작성하고 **추가**를 누릅니다. 내용은 비워 둘 수 있습니다.
3. 목록에서 **완료**를 누르면 `[완료]` 표시와 취소선이 적용됩니다. **완료 취소**로 되돌릴 수 있습니다.
4. **수정**을 누르면 해당 항목 안에 편집 폼이 나타납니다. **저장**으로 반영하거나 **취소**로 편집을 끝냅니다.
5. **삭제**를 누르면 해당 항목이 바로 삭제됩니다.
6. 다른 날짜를 선택하면 그 날짜의 목록으로 전환됩니다.
7. 새로고침한 뒤 같은 날짜를 다시 선택해 저장된 목록을 확인합니다. 선택한 날짜 자체는 저장하지 않습니다.

## 데이터 구조

저장 키는 `hongjeonggi-todos`이며, 다음 형태의 객체 배열을 JSON 문자열로 저장합니다.

```json
[
  {
    "date": "2026-11-17",
    "title": "JavaScript 복습",
    "content": "이벤트 처리와 DOM 조작 정리하기",
    "completed": false
  }
]
```

위 데이터는 구조를 설명하기 위한 예시이며, 앱에 기본으로 들어 있는 데이터는 아닙니다.

### 주요 상태와 함수

| 이름 | 역할 |
| --- | --- |
| `todos` | 전체 날짜의 할 일을 보관하는 배열 |
| `editingIndex` | 현재 수정 중인 항목의 배열 인덱스, 수정 중이 아니면 `-1` |
| `saveTodos()` | 전체 배열을 JSON으로 변환해 `localStorage`에 저장 |
| `renderTodos()` | 선택한 날짜와 수정 상태에 맞춰 목록 DOM을 다시 구성 |
| `stopEditing()` | 수정 상태 해제 |

사용자가 입력한 제목과 내용은 `textContent` 또는 입력 요소의 `value`로 반영합니다.

## 확인 시나리오

- 날짜를 선택하기 전에는 입력 폼이 숨겨져 있고 날짜 선택 안내가 표시됩니다.
- 날짜를 선택하면 입력 폼이 나타나고, 항목이 없으면 빈 목록 안내가 표시됩니다.
- 제목이 빈 문자열이면 할 일이 추가되지 않습니다.
- 서로 다른 날짜에 등록한 항목은 각 날짜에서만 조회됩니다.
- 완료 상태를 변경하면 버튼 문구와 취소선이 함께 바뀝니다.
- 수정 후 저장하면 변경 내용이 반영되고, 취소하면 원래 내용이 유지됩니다.
- 새로고침 후 날짜를 다시 선택하면 저장된 항목과 완료 상태를 확인할 수 있습니다.
- 삭제한 항목은 새로고침 후에도 다시 나타나지 않습니다.

## 제한 사항 및 개선 방향

- 데이터는 **해당 브라우저의 해당 출처(origin)**에만 저장됩니다. 브라우저·기기·접속 주소 또는 포트가 달라지면 저장 공간도 달라질 수 있습니다.
- 브라우저 사이트 데이터를 지우면 할 일도 삭제됩니다. 서버 저장, 로그인, 기기 간 동기화 및 백업 기능은 없습니다.
- 제목 검사는 빈 문자열만 확인하므로 공백만 입력한 제목은 등록할 수 있습니다. `trim()` 기반 검사를 추가할 수 있습니다.
- 삭제 확인 및 실행 취소 기능은 없습니다.
- 저장 데이터 로딩 오류는 콘솔에 출력하지만, 상세한 데이터 구조 검증과 저장 실패 시 사용자 안내는 구현되어 있지 않습니다.
- 현재 데이터는 배열 인덱스로 수정·삭제합니다. 정렬이나 복잡한 필터를 추가한다면 고유 ID 기반 관리로 확장할 수 있습니다.
- Tailwind CSS는 CDN 방식으로 사용합니다. 배포 환경에서는 빌드 기반 스타일 생성 방식으로 전환할 수 있습니다.
